# Golden Gate Motors — منظومة مزاد واستيراد السيارات

> يقرأ Claude Code هذا الملف تلقائيًا. المستخدم يتكلم بالعربية (لهجة ليبية): أجبه بالعربية المبسطة، مختصرًا وصادقًا، ولا تدّعِ نجاح شيء لم تختبره فعليًا.

## ما هو المشروع
منظومة لشركة **Golden Gate Motors** تستورد سيارات من مزادات Copart و IAAI الأمريكية وتبيعها في ليبيا: تتبع السيارة من الشراء إلى الشحن والجمارك والبيع (مزاد حي أو بيع مباشر)، وتحسب التكلفة الواصلة لكل سيارة بعملات متعددة، وتصدّر تقارير Excel/CSV/PDF.

## أين هو
- GitHub: **moaidshubana-eng/Ex-Libya**، الفرع **`claude/funny-knuth-jnhu9o`** (امتداد لـ `claude/peaceful-rubin-2on2mb`)، المجلد **`car-auction/`**.
- هذا المجلد **مشروع مستقل تمامًا** عن بقية Ex-Libya (منصة صرافة NestJS لا علاقة لها بالمنظومة). لا تلمس شيئًا خارجه، عدا `render.yaml` في جذر المستودع (نسخة من ملف النشر).
- ارفع على نفس الفرع. لا تنشئ طلب دمج (PR) إلا إذا طلبه المستخدم صراحةً.

## التقنية
Node.js 22 (ES modules) + Express + PostgreSQL 16 (مخطط `auction`). تبعيات الإنتاج ثلاث فقط: express, pg, exceljs. واجهة عربية RTL بـ JavaScript قياسي بلا خطوة بناء (`public/`). البث اللحظي: SSE + LISTEN/NOTIFY.

## التشغيل المحلي
المتطلبات: Node 22 و Git و PostgreSQL 14+ (أو Docker).
1. قاعدتان: `car_auction` و `car_auction_test`، المستخدم `auction` وكلمته `auction`. أو `docker compose up -d db`.
2. `npm install` ثم `cp .env.example .env`.
3. `npm run db:reset`: يبني المخطط ويبذر بيانات تجريبية وهمية. **يحذف كل البيانات؛ للتطوير فقط، ويرفض العمل مع NODE_ENV=production.**
4. `npm start` ثم http://localhost:4000. حسابات تجريبية، كلمة المرور لكلها `Demo@2026pass`: admin@ / ops@ / accountant@ / sales@ / viewer@ / bidder1@ + `auction.ly`.
5. `npm test` = **147 اختبارًا يجب أن تنجح كلها** (يعيد بناء `car_auction_test`). `npm run test:unit` للوحدة بلا قاعدة.
ابدأ دائمًا بالتأكد أن التشغيل والاختبارات تنجح، وأبلغ بالنتيجة الحقيقية.

## قرارات لا تُعكس بلا إذن المستخدم
- **الربط الآلي مع Copart/IAAI معطّل عمدًا** (`INTEGRATIONS_ENABLED=false` افتراضيًا). تُدخل السيارات يدويًا (زر "إضافة سيارة") أو بملف CSV. كود الربط كامل ومختبر ويُفعَّل لاحقًا بالإعداد؛ لا تحذفه. Copart و IAAI لا تنشران API عامًا: المطلوب لاحقًا مفتاح تغذية عبر حساب العميل أو وسيط مرخّص. لا تُكشط مواقعهما أبدًا.
- الهوية: شعار في `public/brand/` (كحلي #0b1628، ذهبي #c9a96a).
- المبالغ NUMERIC دقيقة (لا float). كل تكلفة تحفظ سعر صرفها لحظة تسجيلها. سجل التدقيق للإلحاق فقط (Trigger). قواعد الأعمال الحرجة مفروضة في قاعدة البيانات نفسها: لا تُضعفها.
- **الخادم هو الذي يفرض الصلاحيات**، والواجهة تخفي فقط. المزايد لا يرى التكاليف ولا الحد الأدنى السري ولا أسماء الآخرين.

## فخاخ تقنية عرفناها
- كل طلب غير GET يجب أن يكون JSON (حماية CSRF)، حتى DELETE بلا جسم؛ `public/js/core.js` يضمن ذلك.
- قوالب `html\`\`` تهرّب كل قيمة. للسمات الداخلية الموثوقة فقط استعمل `raw()` (وإلا تُهمَل required و value).
- معامل SQL واحد يُستعمل كنص وكـ enum في الاستعلام نفسه يفشل: استخدم تحويلًا صريحًا `$2::type_name`.
- `pkill -f "node src/server.js"` داخل أمر bash يقتل الأمر نفسه؛ اقتل بـ PID.

## ما أُنجز
قاعدة 33 جدولًا، إدخال السيارات وتعديلها، الصور (عدسة تكبير + عارض 6×)، مقارنة، شحنات (إنشاء/تحميل/تحديث ينقل السيارات)، جمارك، مزايدة حية (آلية + منع قنص + حد أدنى سري + تأمين)، مزادات وتسجيل مزايدين، عملاء، بيع مباشر ودفعات، تكاليف تفصيلية وتوزيع تكلفة الحاوية بدقة، تقارير Excel/CSV/PDF، موردون، مستخدمون، تغيير كلمة المرور، أسعار الصرف، رفع صور السيارات، حسابات العملاء والموردين وكشوفها (`services/accounts.js`: أرصدة لكل عملة، دفعات على الحساب مع ربط اختياري بسيارة وتحويل بسعر محفوظ، FIFO للمتبقي على كل سيارة)، إيصالات قبض/صرف مسلسلة، لوحة «لنا وعلينا»، مصاريف الشركة وتقرير الربح الشهري (`services/expenses.js`)، تعبئة المواصفات من الـVIN عبر NHTSA vPIC (`services/vin-decode.js`؛ جلسات Claude لا تصل لـNHTSA، فتُختبر بنموذج رد)، 11 وثيقة في `docs/` (ابدأ من `README.md`)، وتقريران للعميل في `docs/client-report/`.

## النشر الحالي
منشورة مجانًا على https://golden-gate-motors.onrender.com (Render خطة free + قاعدة Neon مجانية، مشروع `golden-gate`، Frankfurt) عبر `render-free.yaml`، من الفرع أعلاه. النشر **تلقائي** (Auto-Deploy: On Commit، منذ 2026-11-02 بطلب المستخدم): كل رفع للفرع ينزل فورًا، فلا ترفع إلا ما اختبرته. شبكة جلسات Claude لا تصل إلى onrender.com: اطلب من المستخدم صورة أو سجلات.
- هجرات المخطط: ملفات `db/migrations/NNNN_*.sql` يطبّقها `init-db.js` تلقائيًا عند الإقلاع. لا تعدّل قاعدة الإنتاج يدويًا.
- ملفات الواجهة تُخدم بمسار ذي بصمة (`/v/<hash>/...`) فيصل أي تحديث فورًا. لا تعد تخزين `/js/app.js` بلا بصمة.

## المتبقي (بالأولوية)
1. **الانتقال للخطة المدفوعة قبل المزادات الحية الفعلية** (`render.yaml`): المجانية تنام بعد 15 دقيقة. القرار والبطاقة للمستخدم. لا تطلب منه كلمة المرور ولا المفاتيح.
2. **تقارير العميل** (`docs/client-report/`) تذكر الربط مع Copart كمُسلَّم ولم تُحدَّث بالإدخال اليدوي والعمليات الجديدة. حدّثها بعد موافقته. وأسماء "مقدَّم إلى/من" فيها تحتاج اسمين حقيقيين منه.
3. بعد الإطلاق: جدولة التقارير الكبيرة (تقرير الأسطول ~1.7 ث لـ 20 ألف سيارة، وتصدير Excel الكبير 6–11 ث)، اختبار اختراق مستقل قبل فتح البوابة للمزايدين، وحد المعدل يحتاج Redis أو Nginx عند تعدد النسخ.
