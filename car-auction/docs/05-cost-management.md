# 05 — إدارة التكاليف وتقرير التكلفة لكل سيارة

## 1. نموذج التكلفة

**التكلفة الواصلة (Landed cost)** لكل سيارة = مجموع كل بنودها غير الملغاة، محوّلة إلى الدينار بسعر الصرف المحفوظ مع كل بند.

### 1.1 البنود (19 بندًا في 8 مراحل)

| المرحلة | البنود | العملة المعتادة | مصدر التسجيل |
|---|---|---|---|
| **الشراء والرسوم** | سعر الشراء، رسوم المشتري، رسوم أخرى (بوابة/بيئة/مزايدة إلكترونية)، عمولة الوسيط | USD | **آليًا** من Copart/IAAI عند الاستيراد (+ يدوي للعمولة) |
| **لوجستيات أمريكا** | السحب الداخلي، تخزين/غرامات تأخر السحب، مستندات التصدير والملكية | USD | يدوي (العمليات/المحاسبة) |
| **الشحن البحري** | الشحن البحري، التحميل والتربيط، التأمين البحري | USD | **تكلفة مشتركة** على الحاوية تُوزَّع آليًا + التأمين لكل سيارة |
| **الميناء الليبي** | رسوم التفريغ والمناولة، أرضيات الميناء | LYD | يدوي أو مشترك |
| **الجمارك** | الرسم الجمركي، أتعاب التخليص | LYD | **آليًا** عند تعليم البيان "سُدد الرسم" + يدوي للأتعاب |
| **النقل الداخلي** | النقل من الميناء إلى المعرض | LYD | يدوي |
| **التجهيز** | الإصلاح، قطع الغيار، الترقيم والتسجيل | LYD | يدوي |
| **أخرى** | مصاريف أخرى | أي عملة | يدوي |

البنود جدول بيانات (`cost_categories`) وليست ثوابت في الكود، فيمكن إضافة بند أو تعطيله دون تطوير.

### 1.2 سمات كل بند

| السمة | الغرض |
|---|---|
| المبلغ والعملة (USD / LYD / EUR) | كما في الفاتورة الأصلية |
| `fx_rate_to_lyd` | **لقطة** آخر سعر صرف مسجل في أو قبل تاريخ التكلفة. يُحفظ مع البند، فتعديل الأسعار لاحقًا لا يغير التقارير التاريخية. يمكن تمرير سعر محدد إن اختلف سعر التحويل الفعلي |
| `amount_lyd` | عمود محسوب في قاعدة البيانات = `round(amount × fx, 3)`، فلا يمكن أن يختلف عن مصدره |
| فعلي / تقديري | التقديري (مثل رسم جمركي متوقع لسيارة في البحر) يظهر في التقرير بعلامة `*` ويُستبدل بالفعلي عند وروده |
| مسدد / غير مسدد | لمتابعة المستحقات للموردين (يظهر "غير مسدد" إجمالًا في التقرير ولوحة المؤشرات) |
| المورد ورقم الفاتورة | للمطابقة مع حسابات الموردين |
| الإلغاء | لا حذف أبدًا. إلغاء البند يتطلب سببًا ويُسجَّل في التدقيق (ADMIN/ACCOUNTANT) |

### 1.3 التكاليف المشتركة (الحاوية)

أجرة حاوية 40HC تحمل 4 سيارات تُدخَل **مرة واحدة** على الشحنة، ويوزعها النظام آليًا:

- **بالتساوي**، أو **حسب قيمة الشراء** (السيارة الأغلى تتحمل نصيبًا أكبر).
- **دقة تامة:** الحساب بالمِلّيم (أعداد صحيحة)، وكسور التقريب تُوزَّع بطريقة "الباقي الأكبر". مثال: 1000.001 د.ل على 3 سيارات = 333.334 + 333.334 + 333.333. المجموع يساوي الإجمالي **بالضبط**، وهذا مُختبَر آليًا.
- كل حصة بند مستقل على سيارتها يشير إلى التكلفة الأم (`shared_cost_id`)، فيُعرف مصدرها.

## 2. التقرير التفصيلي

**الشاشة:** تقرير التكاليف (ADMIN، ACCOUNTANT، OPERATIONS، VIEWER، SALES — والمزايد ممنوع).

**المرشحات:** الحالة، الماركة، فترة الإنشاء (من/إلى)، رقم الشحنة.

**المحتوى:**
1. **مؤشرات:** عدد السيارات (والمباعة منها)، إجمالي التكلفة الواصلة (وغير المسدد منها)، إجمالي المبيعات، والهامش المحقق ونسبته إلى التكلفة.
2. **توزيع التكلفة على المراحل:** شريط ونِسَب.
3. **جدول كل سيارة:** رقم المخزون، السيارة، الحالة، المراحل الثماني، الإجمالي (مع `*` إن تضمن تقديرًا)، سعر البيع، والهامش بالأخضر أو الأحمر. صف إجمالي في الأسفل.

### 2.1 التصدير

| الصيغة | المحتوى | ملاحظات تقنية |
|---|---|---|
| **Excel (.xlsx)** | 3 أوراق: (1) **الملخص**: الإجماليات بالمراحل، (2) **تكلفة كل سيارة**: صف لكل سيارة + صف إجمالي **بمعادلات `SUM` حقيقية** + مرشح تلقائي + تجميد الرأس، (3) **البنود التفصيلية**: كل بند بعملته وسعر صرفه وقيمته بالدينار وتاريخه وفاتورته وحالة سداده | ملف xlsx حقيقي (`exceljs`)، كل الأوراق من اليمين لليسار، والأرقام بتنسيق `#,##0.000`. يُبنى في **Worker thread** منفصل حتى لا يعطّل المزايدات الحية أثناء تصدير كبير |
| **CSV** | صف لكل سيارة | UTF-8 مع BOM حتى يفتح بالعربية صحيحًا في Excel. **حماية من حقن الصيغ**: أي خلية تبدأ بـ `= + - @` تُسبق بـ `'` |
| **PDF** | زر "PDF / طباعة" يطبع الصفحة بتنسيق A4 أفقي مخصص | ترويسة (التاريخ، المُصدِر، المرشحات)، رأس الجدول يتكرر في كل صفحة. يُحفظ PDF من حوار الطباعة، فيُنتج عربية سليمة الاتجاه والتشكيل دون مكتبات خطوط |

كل تصدير Excel يُسجَّل في سجل التدقيق (من صدّر، ومتى، وبأي مرشحات).

## 3. الواجهة البرمجية

| الطلب | الصلاحية | الوصف |
|---|---|---|
| `GET /api/vehicles/:id/costs` | قرّاء التكاليف | بنود السيارة + ملخصها بالمراحل |
| `POST /api/vehicles/:id/costs` | ADMIN، ACCOUNTANT، OPERATIONS | `{categoryCode, amount, currency, incurredAt, vendorId?, description?, fxRateToLyd?, status?, invoiceRef?, isPaid?}` |
| `POST /api/costs/:id/void` | ADMIN، ACCOUNTANT | `{reason}` إلزامي |
| `POST /api/shipments/:id/shared-costs` | ADMIN، ACCOUNTANT، OPERATIONS | `{categoryCode, totalAmount, currency, method: EQUAL\|BY_PURCHASE_VALUE, incurredAt}` |
| `GET /api/reports/costs` | قرّاء التكاليف | JSON (يُستخدم للجدول) |
| `GET /api/reports/costs.xlsx` / `.csv` | قرّاء التكاليف | ملفات التصدير بنفس المرشحات |

## 4. ضوابط

- **لا تكلفة على سيارة ملغاة.**
- **الدينار سعر صرفه 1:** قيد CHECK في قاعدة البيانات.
- **لا تكلفة بلا سعر صرف:** إذا لم يوجد سعر مسجل للعملة في ذلك التاريخ، يُرفض البند برسالة واضحة. المطلوب إدخال السعر أولًا.
- **الحصص المشتركة لا تُلغى منفردة:** تُعالج من الشحنة، حتى يبقى مجموعها مطابقًا للإجمالي.
