# 09 — خطة الاختبار والنتائج

> كل النتائج أدناه **مقيسة فعليًا** على هذا الإصدار، لا تقديرية.
> - المخرجات الخام: [`test-results/test-run.txt`](test-results/test-run.txt) و[`test-results/load-test.json`](test-results/load-test.json).
> - البيئة: حاوية Linux بـ 4 أنوية و15GB ذاكرة، Node.js 22.22، PostgreSQL 16، والخادم وقاعدة البيانات ومولّد الحمل على نفس الجهاز.

## 1. استراتيجية الاختبار

| المستوى | الأداة | ما يغطيه | التشغيل |
|---|---|---|---|
| **وحدة** | `node:test` | القواعد النقية: المال، المزايدة، المزايدة الآلية، دورة الحياة، VIN، المحوّلات، عميل HTTP، التشفير، التحقق من المدخلات | `npm run test:unit` (لا يحتاج قاعدة بيانات) |
| **تكامل** | `node:test` + PostgreSQL حقيقي + الخادم الحقيقي على منفذ عشوائي | قيود قاعدة البيانات، الأمان عبر HTTP، التزامن، SSE، الإغلاق الآلي، التكاليف، Excel/CSV، الجمارك، محرك المزامنة | `npm run test:integration` (قاعدة `car_auction_test` تُعاد بناؤها في كل تشغيل) |
| **واجهة (E2E)** | Playwright + Chromium | تشغيل كل الشاشات بدورين، وسطح المكتب والجوال، والوضع الداكن، والتقاط أخطاء JavaScript | `npm run screenshots` |

| **التكامل المستمر** | GitHub Actions (`.github/workflows/ci.yml`) | كل ما سبق عدا الأداء والواجهة، على PostgreSQL 16 | عند كل push |

### 2.2 اختبارات التكامل (40)

| المجموعة | العدد | الحالات |
|---|---:|---|
| قيود قاعدة البيانات | 6 | Trigger يرفض انتقالًا غير مسموح **حتى بـ UPDATE مباشر**؛ رفع التعليق؛ سجل التدقيق يرفض UPDATE/DELETE؛ سعة الحاوية؛ قيد VIN؛ العمود المولّد للدينار |

| التكاليف والتقارير | 7 | سعر الصرف الساري في تاريخ التكلفة؛ الإلغاء يتطلب سببًا ولا يحذف؛ التوزيع المشترك = الإجمالي بالضبط (1000.001)؛ المزايد لا يضيف تكلفة؛ **Excel صالح بثلاث أوراق وإجمالياته = قاعدة البيانات وعدد بنوده = عدد البنود الفعلية**؛ CSV بـ BOM **وتحييد حقن الصيغ**؛ الجمارك: سداد الرسم يُسجَّل تكلفة، والإفراج ينقل السيارة |
| محرك المزامنة | 7 | استيراد جديد بتكاليفه؛ **إعادة نفس البيانات لا تكتب شيئًا**؛ تقدم متعدد المراحل خطوة خطوة + **احترام الحقول المقفلة**؛ عنصر تالف إلى طابور الأخطاء دون إيقاف الجولة، وتكراره لا يضاعف الصفوف؛ **قاطع الدائرة بعد 3 إخفاقات** + التشغيل اليدوي + إعادة الضبط بالنجاح؛ منع جولتين متزامنتين؛ استيراد CSV عبر الواجهة |

### 2.3 الواجهة (E2E)

19 لقطة لكل الشاشات (سطح المكتب، الجوال 390px، الوضع الداكن) بلا أي خطأ JavaScript في الصفحة. التقاط `pageerror` مفعّل في السكربت. أخطاء 401 في وحدة التحكم هي فحص الجلسة قبل الدخول، وهذا متوقع. سيناريو إضافي: موظف مبيعات يدرج سيارة في المزاد الحي من ملفها، ثم يزايد نيابة عن عميل. نجح.

**المزايدة:** 903 مزايدة قُبلت (201) و100 رُفضت لأسباب منطقية: سبقتها مزايدة أعلى، أو المزايد هو الأعلى أصلًا (422). صفر أخطاء خادم. كل مزايد يزايد مرة كل ~0.9 ثانية، وهذا أسرع بكثير من أي مزاد حقيقي.

**سلامة البيانات بعد الضغط** على اللوتات الثلاثة (298 + 314 + 315 = 927 مزايدة): السجل متصاعد بصرامة، والسعر الحالي = آخر مزايدة، وعدّاد المزايدات = عدد الصفوف: **100% في الثلاثة**.

**البث اللحظي (SSE):** 300 متصفح متصل باللوت نفسه، و**وصلت المزايدة للـ 300 جميعًا**: p50 = 29ms، p95 = 40ms، الأقصى 41ms.
